# UPEmissor — instaladores

Emissor de RPS (Recibo Provisório de Serviços) no padrão ABRASF do **UPGestão**, da
[WGB Soluções](https://wgbsolucoes.com.br/produtos/upemissor). Funciona sem internet e converte os
RPS em NFS-e enviando o lote à prefeitura.

Este repositório guarda **só os instaladores** — a última versão está em
[Releases](https://github.com/wagnergrilojunior/upemissor-downloads/releases/latest):

| Sistema | Arquivo |
|---|---|
| Windows 10 ou 11 (64 bits) | [UPEmissor-windows.exe](https://github.com/wagnergrilojunior/upemissor-downloads/releases/latest/download/UPEmissor-windows.exe) |
| macOS 11 ou mais novo (Intel e Apple Silicon) | [UPEmissor-mac.dmg](https://github.com/wagnergrilojunior/upemissor-downloads/releases/latest/download/UPEmissor-mac.dmg) |
| Linux (64 bits) | [UPEmissor-linux.AppImage](https://github.com/wagnergrilojunior/upemissor-downloads/releases/latest/download/UPEmissor-linux.AppImage) · [UPEmissor-linux.deb](https://github.com/wagnergrilojunior/upemissor-downloads/releases/latest/download/UPEmissor-linux.deb) |

O acesso é o mesmo do Portal do Contribuinte do seu município.
